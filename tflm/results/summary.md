## 讀法

- **Invoke** 是推論本身，各配置要比的就是這一欄。
- **B1C / B1D** 把 B1 的兩項改動拆開（只開 1x1 / 只開 depthwise），
  用來歸因加速來源。加速比不可相乘，但**節省量可以相加** ——
  因為兩項動的是互不相交的 operator。
- **AllocateTensors** 含 Prepare 的浮點工作（`frexp` + double 除法），
  一次性，不該算進加速比。
- **框架 overhead** = Invoke 減掉所有 kernel 的和。B0 量到只有數千條
  指令（約 0.00002%），所以框架精簡在速度上沒有空間 —— B1 的價值
  在 code size。
- **.text** 不含模型（模型在 .rodata，約 5.3 MB）。B1 的 code size
  改善要看這一欄。
- **判定** 必須是 BITEXACT：每個配置都要跟 x86 的 B0 輸出位元相同。
  B1/X1 只是換實作，數學上完全等價，差一個 bit 就是寫錯了。
